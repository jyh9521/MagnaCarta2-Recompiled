# 构建与发布门槛

1. 干净 checkout 运行 `python -m unittest discover -s tests -v`。
2. 运行正式目录校验；扫描用户原版数据并确认哈希。
3. 检查 git 暂存列表：禁止 AGENTS.md、LOCALIZATION_STANDARD、镜像、XEX、资源、反编译输出、凭据及个人路径。
4. 只打包自编工具/文档。当前阶段无原生程序和中文补丁可发布。
5. 未来补丁构建需验证版本、期望字节与输出结构；失败必须停止。
6. 运行发布产物的独立安装/卸载/回退测试，再记录版本、哈希、提交与远端状态。

第一轮源码回退为本地哈希守卫脚本，只测试隔离副本；禁止对原版 ISO 做修改实验。
