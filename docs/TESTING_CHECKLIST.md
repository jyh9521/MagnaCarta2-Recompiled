# 测试清单

## 记录格式
每次记录环境、构建/代码哈希、输入、命令、预期、实际输出、退出状态、日志路径。
状态仅 PASS / FAIL / BLOCKED / NOT TESTED。空测试运行不能标记工具 PASS。

## 第一轮
- 目录递归、SHA-256、大小、Unicode、空文件、错误输入、读取异常、只读行为：自制样本自动测试。
- XDVDFS 固定头、目录遍历、范围、环、路径、嵌套目录：自制样本与双盘只读清单。
- 双盘比较：同名同内容/不同内容/独有，拒绝不完整清单。
- 本地化：稳定 ID、字段、保护 token、审核门槛；空正式库仅验证结构，不验证翻译质量。
- 构建、API、内存、文件系统、输入、音频、图形、存档：NOT TESTED。
- 标题、新游戏、移动、战斗、任务、场景、视频、换盘、保存/读档、通关：NOT TESTED。

本地详细日志位于 local/analysis/phase1/；公开摘要见 PHASE1_RESULTS。
